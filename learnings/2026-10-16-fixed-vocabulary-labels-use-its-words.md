# A label from a fixed vocabulary must use the vocabulary's words

**What happened.** An earlier fix changed a document's classification label to a plausible
word that is not one of the organization's classes. It spread to the cover, every footer
and the sign-in page.

**Why.** The fix chose a word that sounded right instead of the organization's term.

**Do instead.** For a classification, a status or any label with a fixed set of values,
find or ask for the set before writing one. And a page anyone can reach, such as a sign-in
page, names no client, project or classification.

**Evidence.** Corrected to the organization's own class, and the sign-in page made plain.
